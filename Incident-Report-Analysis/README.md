# Incident Analysis and Response: Denial of Service Attack

## Scenario
Investigated a Denial of Service (DoS) attack against a multimedia company. A malicious actor exploited an unconfigured firewall to flood the internal network with ICMP packets, disrupting network resources for two hours.

## Implemented Mitigations
* **Firewall Configuration:** Added rules to limit the rate of incoming ICMP packets and enabled source IP verification to block spoofed addresses.
* **Network Monitoring:** Deployed monitoring software to detect abnormal traffic patterns in real-time.
* **IDS/IPS Integration:** Implemented Intrusion Detection and Prevention Systems to filter traffic based on suspicious characteristics.

## Task
Developed a comprehensive network security improvement strategy utilizing the **NIST Cybersecurity Framework (CSF)**. The incident analysis was categorized into the five core functions:
* **Identify:** Audit internal networks, systems, and access privileges to locate security gaps.
* **Protect:** Implement tools, policies, and training to mitigate future threats.
* **Detect:** Enhance monitoring capabilities for faster, more efficient threat detection.
* **Respond:** Contain and analyze security incidents while improving response processes.
* **Recover:** Restore affected systems and data to normal operations.
